🕯️ GhostWire

A séance for dead file formats & forgotten internet tools — Día de los Muertos for the software we grew up on. Name a format, a tool, or a memory; the medium (a tiny language model trained in this repo, running locally) answers with an ofrenda card.

The terminal waits. Leave an offering: a name from the old web.
Zero servers were haunted in the making: retrieval (TF-IDF) and generation (trigram model, weights in model/weights.json) run entirely on your machine. MIT licensed.
